# Iman — Mac-only development

The iPhone companion has been retired at the owner's request on October 13, 2026.

The phone source and iOS cloud-build workflow have been removed from the current branch. Development continues in the local Mac project. The Mac app does not require AltStore, Apple sign-in, phone pairing or the former Wi-Fi gateway.

Earlier commits remain in Git history. This repository no longer builds or distributes an iPhone app.
